IDEA REPORT v2

こどもの無限のイメージを、
こどもの手で、かたちに。

v2の転換点はひとつ。作るのも、ぜんぶこども。大人は魔法使いを降り、ファシリテーターになります。魔法の正体は「朝、できていた」ではなく、「じぶんの手で、さいごまで作れた」に変わります。

CONCEPT NAME（仮）こどもへんしん工房
つくるのは、こども。おとなは、といかけるだけ。
STARTING POINT

問いを、ひっくり返す

子どもの想像力は、足りないことがありません。忍者の歴史ゲーム、動く工作、ひみつのカードゲーム——アイデアは毎日、無限に湧いています。

作るべきものは「想像させる装置」ではなく、湧いた想像が、こどもの手でかたちになる前に消えていく場所をふさぐ装置です。想像は決まった4つの場所で死んでいます。

死因 1

忘れる

思いついた瞬間がいちばん熱いのに、書き留める手段がなくて夕方には消えている。

→ 対策：捕まえる装置（タネポスト）
死因 2

大きすぎて作れない

頭の中は映画級。でも真っ白な紙から作るのは大人でも難しい。落差にがっかりして手が止まる。

→ 対策：7割空白のキット棚（半完成の魔法）
死因 3

「ゲーム＝アプリ」だと思い込む

かたちの選択肢を知らないから、一番作りにくい形（アプリ）しか思い浮かばず諦める。

→ 対策：かたちのメニュー（へんしんカード8種）
死因 4

誰にも見てもらえない

作っても遊んでくれる人がいなければ、2作目は生まれない。承認のループが切れている。

→ 対策：発表と商いの場（ワンダーまつり）
隠れた死因が2つあります。ひとつは「完成しないと価値がない」という思い込み（→そうぞうずかんが解毒します）。もうひとつは、v1で見落としていた最大のもの——大人が代わりに作ってしまうこと。完成度は上がりますが、「じぶんが作った」という所有感が死にます。v2はこれを工房の第一の掟にしました。
CORE PRINCIPLE

半完成の魔法 — 70%の空白

「作るのもこども」を成立させる工学的な鍵は、素材の完成度をどこに設定するかです。真っ白な紙は難しすぎて手が止まり、完成品は自分のものになりません。答えはあいだ——骨組みの3割だけができていて、7割が空白のキットです。

できている 30%
（枠・ルールの骨・とじしろ）
こどもがうめる 70%
（絵・ことば・ルール・キャラ・かざり）

すごろくキットなら「マスの枠と分岐だけ印刷済み」。マスの中身・イベント・ゴールの物語は全部こどもが書く。

この30%を用意するのがファシリテーターの仕事のほぼすべてです。当日は手を出しません。大人の労働を「当日の代作」から「前日の仕込み」へ移す——これがv2の構造転換です。

MAIN CONCEPT

こどもへんしん工房 — 4つの装置

家の中に流れる「想像の製造ライン」。ラインに立つのは全工程こどもです。入口は紙と声と写真。デジタルとAIは棚の中の道具のひとつに過ぎません。

装置 1
📮

タネポスト

思いついたら10秒で投函。絵ハガキ・ボイスメモ・落書きの写真、なんでもOK。捨てられるタネはゼロ。

装置 2
🗄️

へんしんキットだな

8つのかたちに対応する「7割空白キット」の棚。こどもがタネとキットを選び、自分の手で埋めて完成させる。

装置 3
📖

そうぞうずかん

作られなかったタネも全部、No.付きでこどもが登録。「未完成」が「コレクション」に変わる。

装置 4
🎪

ワンダーまつり

月1回の家族フェス。こどもが店長。値段も口上もこどもが決め、大人はお客さんとして買うだけ。

AIのいる場所 — 「道具箱の中」

v1でAIは大人の裏方でしたが、v2では棚の中の道具のひとつとして、こどもが自分で使います。ただし役割を厳しく限定します：AIにやらせてよいのは「材料出し」（クイズの問題案、キャラの名前案、色ぬり用の下絵）まで。選ぶ・組み立てる・完成させるのは必ずこどもの手。マイクで話しかけられて、ふりがな付きで返す「工房のそうだん窓口」として1台置くイメージです。使うかどうかもこどもが決めます。

ミニゲーム

問題やキャラを書き込むシート。AI窓口に渡すと動くゲームになる（唯一の共同製作）

順番に意味があります。アプリ（ミニゲーム）を8番目・最後に置きました。7つの紙のかたちで「作る→遊ばれる」の成功体験を積んだこどもだけが、最も工程の長い8番に挑む——という難易度の階段です。8番だけは「こどもが設計図シートを書き、AI窓口が組み立てる」共同製作で、ここでも設計者はこどもです。
GROWN-UPS

ファシリテーターの3つの技

大人の仕事は、教えることでも作ることでもありません。環境をつくる・といかける・手を出さない——この3つだけです。

① 前日にしこむ

キット棚の補充、はさみ・のり・印刷の準備、AI窓口の設定。大人の創意工夫はぜんぶ「前日まで」に使い切る。

② 質問だけで進める

詰まったこどもに答えを渡さず、問いを渡す。問いは下の「ファシリテーターカード」から選ぶだけにして、思いつきの助言を封じる。

③ 手を出さない・直さない

ルールが破綻したすごろくも、そのまま完成させて一度遊ぶ。「遊んでみてどうだった？」が最高の審査官。修正はこどもが決める。

ファシリテーターカード（問いかけ集・抜粋）：
「それ、だれが遊ぶの？」／「いちばん見せたいところはどこ？」／「もし1つだけルールを足すなら？」／「きょう完成させるなら、どこをあきらめる？」／「おきゃくさんは、いくらなら買うと思う？」／「つぎのタネはもう決まってる？」

守ること（工房の掟）

① 大人は作品に触らない。直したくなったら質問に変換する。
② 既存のキャラクター（有名アニメ等）はそのまま使わず、「オリジナルのにたキャラ」に変身させてから形にする。
③ 外に売るのは第2段階から。家の外での販売や収益化を始める前に、大人側の勤務規程の確認を必ず先に済ませる。
④ タネは絶対に捨てない。ずかん登録もこども自身がやる。

ALTERNATIVES

別方向の「something wonderful」3案

重心の違う3方向。いずれも「作り手はこども・大人はファシリテーター」で読み替えてあります。

案 B

こども放送局 🎙️

こどもが局長・ディレクター・出演者を兼ねる家の放送局。週1回の番組（クイズ・発明ニュース・ラジオドラマ）を企画→収録→放送まで自力で回す。大人は「スタジオの整備係」と「一視聴者」。

強み：毎週の放送日が継続装置になる。声だけなので低学年でも全工程を握れる。弱み：工作系の興味を吸収しにくい。

案 C

100のタネ美術館 🖼️

こどもが館長。展示・キャプション書き・企画展のテーマ決めまで館長の仕事。大人は「建物（壁とフレーム）の提供者」で、展示内容には口を出さない。

強み：準備が最少で、未完のアイデアが最初から主役。弱み：「動くものを作りたい」欲求には応えない。

案 D

こども発明会社ごっこ 🏢

こどもが社長。家族が「お客さん」として注文書を出し、こどもが企画書→試作→納品→請求書ごっこまで行う。大人は発注と支払いだけを行う顧客役で、製造工程には立ち入れない。

強み：「商品化をこども目線で」に最短。依頼駆動なのでネタ切れしない。弱み：自由発想より受注が主役になりがち。

FIRST MAGIC

最初の魔法実験 — 週末の半日

v2の魔法は「朝の驚き」ではなく「自分の手の中」で起きるので、ひと晩の仕込みは不要。半日で完結します。

  1. 前日：ファシリテーターの仕込み（60分）：キットを2種類だけ用意する（おすすめ：すごろくの空白盤＋空白カード20枚）。ファシリテーターカードを5枚書く。当日の自分の役割を「質問と拍手だけ」と決めておく。
  2. 当日朝：ポストを作る（20分）：空き箱にこどもが色を塗り、「タネポスト」と名付ける。ここからの決定権はすべてこども。
  3. タネを3つ投函してもらう（20分）：「思いついたこと、なんでも絵か言葉で」。書けなければ声で録音してもよい。上手さは問わない。
  4. タネ1つ＋キット1つを、こどもが選ぶ（10分）：2種類のキットを並べて「どっちのかたちに変身させる？」。選んだ理由は聞いてもいいが、選択には介入しない。
  5. 製作タイム（60〜90分）：こどもが7割の空白を埋める。大人は同じ机で「自分のタネ」を作っていてよい（隣で作る大人は、監督ではなく仲間になる）。詰まったらカードの問いを1枚だけ出す。
  6. 完成したら、すぐ遊ぶ（30分）：破綻していてもそのまま一度遊び切る。感想は「おもしろかった所」を1つだけ伝える。直すかどうかは、こどもが決める。
  7. 判定（夜）：合格条件は2つ——「最後の工程まで、こどもの手で終わったか」「頼まれずに、次のタネが投函されたか」。前者が×なら空白率を下げ（半完成をもう少し完成寄りに）、後者が×なら遊ぶ相手を増やして翌週もう1回。

まとめ — v2で何が変わったか

  • 魔法の正体を「朝、できていた」から「じぶんの手で作れた」に交換した。所有感こそが2作目を生む。
  • 成立の鍵は半完成の魔法（70%の空白）。大人の創意は当日の代作ではなく、前日の仕込み＝キット作りに使う。
  • AIは大人の裏方から、こどもが自分で使う道具箱の一つへ。ただし「材料出し」まで。選ぶ・組む・仕上げるのはこどもの手。
  • アプリは8つのかたちの8番目＝最終ステージ。紙の7つで成功体験を積んだ先にある。
  • 大人の技は3つだけ：前日にしこむ・質問だけで進める・手を出さない。問いはカード化して即興の助言を封じる。
  • 最初の一歩は週末半日の魔法実験。合格条件は「こどもの手で完走」＋「頼まれず2個目のタネ」。
