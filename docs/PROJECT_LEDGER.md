# 制約台帳：こども創作OS（仮称：つくるクエスト）　最終更新：2026-07-05
保管先: （依頼者が記入：例 Googleドライブ/fable/台帳/）

### 1. 目的（何が変われば成功か）
子どもが自分の興味から出たアイデアを、大人の助けを最小限に、遊べる形（アプリ/工作キット）まで自力で持っていけるようになる。商品化体験は従、外部販売・事業化は第2段階。

### 2. 対象者
自分の子ども（小学生・中学受験準備中）＋家族。第2段階で他の子ども・外部。

### 3. 絶対に守ること（不変条件）
- 外部への販売・収益化を始める前に、公務員の兼業許可を確認する（法的ゲート）
- 既存IP（ポケモン等）をそのまま使わない。ウィザードに「オリジナル化」ガードレールを入れる
- 子どもが一人で操作できるUI（ふりがな・大ボタン・TTS）
- 個人情報・実名を作品データに含めない
- 既存の受験クエストOSエンジンとJSON形式（juken-pack等）を壊さない。追加はコンテンツパックとして行う
- 中学受験の学習時間を侵食しない（創作は週の上限時間内、または学習連動）
- 量の表記はグラム・大さじ・小さじのみ（工作キットのレシピ的記載時）

### 4. 変更禁止範囲
既存エンジンのコア／juken-pack@1形式／確定済みの受験スケジュール

### 5. 置かれた仮定（覆したら日付を入れて更新）
- 仮定1：主目的は創造性育成、商品化体験は従、事業化は第2段階（2026-07-05）
- 仮定2：対象は小5女子（歌・英語・美術）＋小3男子（リズム感・ヒップホップ）（2026-07-05）
- 仮定3：作り手はこども・大人はファシリテーター・前日に70%空白キット準備方式（更新2026-07-05）
- 仮定4：画面型アプリ・親ゲート付き・ビートメーカー（4トラック×16ステップ）がv1の唯一の創作モード（2026-07-05）
- 仮定5：10〜20分の短時間セッションで、ふわふわして逃げたいエネルギーを創作に変換できる（未検証・実機で確認）（2026-07-05）
