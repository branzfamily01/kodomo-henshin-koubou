# ビートポン工房｜こどもへんしん工房

小学生が自分の手でリズムを組み立てる、4トラック×16ステップのブラウザ音楽スタジオです。親が1日の営業時間とパスワードを設定し、時間切れ時は「閉店」として編集中作品を自動保存します。

## 公開

リポジトリ直下をそのまま GitHub Pages で公開できる構成です。公開起点は `index.html` です。

## 主な機能

- 4トラック（ドン / タン / チキ / ポン）×16ステップ
- Web Audio APIによる音源合成（マイク不使用・外部素材なし）
- 80〜160 BPM
- 2プロフィール
- 完成作品 / 「タネ」作品の保存・再編集
- 1日の営業時間・残り時間表示
- 残り3分通知
- 時間切れ時の編集中作品自動保存
- 親パスワードによる +5 / +10 / +15分延長
- 親パネルからプロフィール名・営業時間・パスワード変更
- JSONバックアップ / 復元
- localStorageのみで動作

## スマホUIの設計判断

内部データは4×16を維持しつつ、375px幅でもセルを押し分けられるよう、シーケンサー表示は `1–8` / `9–16` の2ページ切替にしています。16列を無理に縮小せず、子どものタップ精度を優先した実装です。

## ファイル構成

- `index.html` — 公開起点
- `style.css` — UIスタイル
- `app.js` — 互換ローダー
- `app-core.js` — 設定・時間管理・画面遷移
- `app-studio.js` — シーケンサー・音声・保存・ギャラリー
- `docs/` — 元の設計資料・制約台帳・実装仕様
- `archive/` — 旧コンセプト

## データ

localStorageキー: `beatpon_v1`

```json
{
  "settings": {"passHash":"...","dailyMin":15,"names":["...","..."]},
  "usage": {"date":"YYYY-MM-DD","usedSec":0,"bonusSec":0},
  "works": []
}
```

パスワードはSHA-256ハッシュで保存し、平文保存しません。
